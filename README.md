## ✨ Features

| Feature | Description |
|---------|-------------|
| 📝 **Dynamic Resume Builder** | Add/remove skills, education, experience, projects as blocks. Live A4‑optimised preview. |
| 📄 **PDF Import & Auto‑Fill** | Upload an existing resume PDF – extracts text and fills all fields automatically. |
| 🤖 **ATS Score Analyzer** | Pastes or uploads PDF/image – computes ATS score (0‑100) and gives improvement tips. |
| 🏅 **Certificate Generator** | Creates a beautiful verifiable certificate with QR code. Choose from **Gold, Blue, Green** templates. |
| 📁 **Local Storage** | All resumes and certificates are saved in your browser – no database needed. |
| 🔍 **Verify Certificate** | Anyone can verify a certificate by entering its ID. |
| 📊 **Dashboard** | Overview of total resumes, average ATS score, and recent certificates. |
| 🖨️ **PDF Export** | Export any resume as a print‑ready A4 PDF. |
| 📱 **Fully Responsive** | Works on desktop, tablet, and mobile. |

## 🛠️ Tech Stack

- **HTML5** – Structure  
- **CSS3** – Styling, responsive layout, print styles  
- **JavaScript (ES6)** – Dynamic UI, ATS scoring, PDF parsing  
- **PDF.js** – Text extraction from PDFs  
- **Tesseract.js** – OCR for image uploads  
- **QRCode.js** – Generate QR codes on certificates  
- **html2canvas + jsPDF** – PDF export of resumes  
- **LocalStorage** – Persistent data storage
